# AI 工程从零到一 · 中英双语阅读版

A mobile-first, single-file bilingual (EN/中文) reader for the open-source curriculum
[rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch) (MIT).

**在线阅读 / Read online:** https://zonlic0925-boop.github.io/ai-engineering-course-zh/

## 特性 / Features

- 523 节课程全量收录（英文原文），20 个阶段，约 342 小时课程量
- 41 节精选课程提供中英对照全文（构建与部署 AI 应用 / MCP / 智能体工程师 三条官方学习路线）
- EN / 中 / 双语 三档切换；双语模式逐节对照，代码块自动去重
- 全部课程标题与阶段简介已翻译为中文，目录支持中英文搜索
- 阅读进度、断点续读、课后自测、字号调节、深色模式（本地存储，无账号）
- 单个 HTML 文件，无外部依赖，首次加载后可离线阅读
